## 先记住这几种 shape

```text
()        标量，一个数
(3,)      长度为 3 的向量
(3, 1)    3 行 1 列
(1, 3)    1 行 3 列
(2, 3)    2 行 3 列
```

看起来都是“几个数”，但模型和矩阵乘对 shape 很敏感。

## 索引和切片

```python
matrix[0]          # 第 0 行，shape (3,)
matrix[:, 1]       # 所有行的第 1 列，shape (2,)
matrix[0, 1]       # 第 0 行第 1 列，标量
matrix[0:2, 0:2]   # 前两行、前两列，shape (2,2)
```

`:` 的意思是“这一维全要”。

- `matrix[0]` 是第 0 行；
- `matrix[:, 1]` 是第 1 列，不是第 1 行；
- Python 下标从 0 开始。

## reshape：只改形状，不改数据顺序

`(2,3)` 有 6 个元素，改成 `(3,2)` 还是 6 个：

```text
[1 2 3]      [1 2]
[4 5 6]  →   [3 4]
             [5 6]
```

- 元素总数必须对得上，否则报错；
- `-1` 表示“这一维你自己算”；
- 数据按行优先展开，不会打乱顺序。

```python
tf.reshape(vector, (-1, 1))   # (3,1)
tf.reshape(vector, (1, -1))   # (1,3)
```

## `@` 和 `*` 不是一回事

```python
a @ b   # 矩阵乘
a * b   # 逐元素乘
```

矩阵乘要求左边的列数等于右边的行数：

```text
(2,3) @ (3,2) -> (2,2)
(2,2) @ (2,2) -> (2,2)
(2,3) @ (2,3) -> 报错
```

遇到矩阵乘报错，先打印两边 shape，检查中间那个维度。

## 广播：shape 不一样时怎么加

广播就是：两个 shape 不一样时，TensorFlow 按规则把其中一个“虚拟扩展”，让它们能逐元素相加。

从最右边一维开始对齐，逐维比较：

- 相等 → 可以；
- 其中一个是 1 → 可以，扩展成另一个的大小；
- 缺维度 → 当成 1；
- 其他情况 → 报错。

输出 shape 是每一维的较大值。

### `(3,1) + (3,)` 为什么可以

```text
column:  (3, 1)
vector:     (3,)  → 当成 (1, 3)
```

逐维比较：

```text
第 0 维：3 和 1 → 3
第 1 维：1 和 3 → 3
结果：(3, 3)
```

数据上相当于：

```text
[[1],        [[1, 2, 3],
 [2],   +     [1, 2, 3],
 [3]]         [1, 2, 3]]
```

结果是：

```text
[[2, 3, 4],
 [3, 4, 5],
 [4, 5, 6]]
```

### `(2,3) + (2,)` 为什么不行

```text
matrix: (2, 3)
vector: (2,)  → 当成 (1, 2)

最后一维：3 和 2，既不相等，也没有 1 → 报错
```

`(2,)` 不是 `(2,1)`。如果想“每一行加自己的数”，要写成：

```python
row_bias = tf.reshape(tf.constant([10, 20]), (-1, 1))  # (2,1)
matrix + row_bias                                     # (2,3)
```

### 能加 / 不能加，看这张表

| 左边 | 右边 | 结果 | 含义 |
|---|---|---|---|
| `(2,3)` | `(3,)` | `(2,3)` | 每一行加同一个向量 |
| `(2,3)` | `(2,1)` | `(2,3)` | 每一行加自己的数 |
| `(2,1)` | `(1,3)` | `(2,3)` | 两两组合的外和 |
| `(3,)` | `(3,)` | `(3,)` | 逐元素加 |
| `(3,1)` | `(3,)` | `(3,3)` | 列 + 行，外和 |
| `(2,3)` | `(2,)` | 报错 | `(2,)` 当成 `(1,2)`，最后一维不匹配 |
| `(2,3)` | `(3,1)` | 报错 | 第 0 维 2 和 3 不匹配 |

### 广播在模型里用在哪

**1. 加偏置**

```python
y = x @ W + b
```

`x @ W` 是 `(N, out_features)`，`b` 是 `(out_features,)`，每一行加同一个偏置。全连接层、卷积层都常见。

**2. 按通道归一化**

图像 `(N,H,W,C)` 减去每个通道的均值 `(C,)`，或乘每个通道的系数 `(C,)`。

**3. 每个样本加自己的偏移**

`(N, features) + (N, 1)`，每一行加不同的数。

**4. 两两组合**

`(N,1) + (1,M)` 得到 `(N,M)`，可以构造两两差值、距离矩阵。

### 最容易踩的坑

```python
labels = tf.constant([0, 1, 1])              # (3,)
preds  = tf.constant([[0.1], [0.2], [0.3]])  # (3,1)

preds - labels   # 结果 (3,3)，不是 (3,1)
```

很多人想逐样本算误差，结果广播成了 `(3,3)`。

要么统一成 `(3,1)`：

```python
labels = tf.reshape(labels, (-1, 1))
preds - labels
```

要么统一成 `(3,)`：

```python
preds = tf.reshape(preds, (-1,))
preds - labels
```

### 怎么避免广播坑

- 先 `print(a.shape, b.shape)`；
- 想清楚每一维代表什么：batch、特征、通道、时间；
- 不确定就 `reshape` / `tf.expand_dims` 明确维度；
- 结果 shape 比预期大，先怀疑广播；
- 广播输出会实际分配内存，shape 太大时要小心。
