# 从这儿开始

这里不搞章节和作业，是咱俩动手的地方。

每个目录是一个小练习，有代码、有解释、有可以自己改的地方。你不需要一次看完，跑通一个再往下。

代码里逐行写了注释，讲每个 API 的参数和 shape；README 讲思路、结果和坑，不再重复抄一遍代码。

下面命令里的 `cd practice/...` 都假设当前在 `tensorflow-learning` 目录下。

## 怎么用

1. 先跑代码，再看解释；
2. 改一行，再跑一次；
3. 报错先看最后一行，再往上找自己的文件；
4. 遇到抽象概念，先查 `../concepts.md`；新的 Python 概念记到 `../python-notes.md`；
5. 一个跑通，再进下一个。

别急着赶进度。把一个小东西跑明白，比看完十个教程有用。
