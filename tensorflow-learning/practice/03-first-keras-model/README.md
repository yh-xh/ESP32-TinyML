# 第一次用 Keras 训练模型

前面只是在看张量。这次开始真正训练：给模型一批数据，让它自己把 `cos(x)` 学出来。

代码里每个 API 的参数和 shape 都写了注释；这份文档讲的是：为什么这样搭、训练出来怎么看、哪些地方容易误解。

## 先跑

```bash
conda activate tf-esp
cd practice/03-first-keras-model
python first_model.py
```

200 个 epoch 在这台机器上大约一两分钟。代码里 `verbose=2`，每个 epoch 会打印一行，不会看起来像卡死。

## 这条链路在做什么

```text
造数据        x -> y = cos(x)
搭模型        1 -> 32 -> 32 -> 1
compile       选优化器和损失
fit           反复前向、算 loss、反向传播、更新参数
predict       拿几个点看结果
save          存成 .keras
```

## 数据

```text
x: (10000, 1)   float32
y: (10000, 1)   float32
```

- `np.linspace` 在 `[0, 2π]` 均匀取 10000 个点；
- `reshape(-1, 1)` 把 `(10000,)` 变成 `(10000, 1)`，每个样本 1 个特征；
- `np.cos` 逐元素算目标值，范围 `[-1, 1]`；
- `astype(np.float32)` 和 TensorFlow 默认类型对齐。

为什么非要二维？因为 Keras 把最后一维当特征维。哪怕只有一个特征，也要写成 `(样本数, 1)`。

## 模型

```text
1 -> 32 -> 32 -> 1
```

`Dense` 里做的是：

```text
z = x @ W + b
a = relu(z)        # 最后一层不加 relu
```

### W 和 b 的 shape

```text
W shape = (这一层的输入维度, 这一层的神经元数)
b shape = (神经元数,)
```

| 层 | 输入 | 神经元 | W shape | b shape | 参数量 |
|---|---:|---:|---|---|---:|
| `Dense(32)` | 1 | 32 | `(1,32)` | `(32,)` | 64 |
| `Dense(32)` | 32 | 32 | `(32,32)` | `(32,)` | 1056 |
| `Dense(1)` | 32 | 1 | `(32,1)` | `(1,)` | 33 |

总参数：

```text
64 + 1056 + 33 = 1153
```

`model.summary()` 里的 `4.50 KB` 是 1153 个 float32 权重的原始大小：

```text
1153 × 4 字节 ≈ 4.50 KB
```

### 为什么中间要 ReLU

如果两层都不加激活：

```text
第二层(第一层(x)) = W2(W1x + b1) + b2
                  = (W2W1)x + (...)
```

最后还是 `x` 的一次函数，叠多少层都一样。ReLU 让模型能拼出弯的曲线。

### 为什么最后一层不加激活

`cos(x)` 有负值：

- 加 ReLU 会把负数截成 0；
- 加 sigmoid 会把输出压到 `0~1`；
- 线性输出可以让模型自己决定范围。

回归任务的最后一层通常就是线性输出。

### 多加一层会怎样

如果加在最后的 `Dense(1)` 前面：

```text
1 -> 32 -> 32 -> 32 -> 1
```

新层是 `32 -> 32`，W 是 `(32,32)`，b 是 `(32,)`，多 1056 个参数。总参数：

```text
64 + 1056 + 1056 + 33 = 2209
```

固定宽度时，每加一层只是线性增加参数，不会指数爆炸。真正容易让参数变多的是宽度和输入维度，比如把图像拉平后接 Dense。

## compile 和 fit

```python
model.compile(
    optimizer=tf.keras.optimizers.Adam(1e-3),
    loss="mse",
)
```

- `optimizer`：怎么更新参数，Adam 是常用优化器；
- `1e-3`：学习率，控制每次更新的步长；
- `loss="mse"`：均方误差，回归任务常用。

`fit` 里最关键的三个参数：

```text
epochs=200       把全部数据重复 200 遍
batch_size=64    每次拿 64 个样本更新一次参数
verbose=2        每个 epoch 打印一行
```

计算一下：

```text
10000 / 64 ≈ 157 个 batch/epoch
157 × 200 ≈ 31,400 次参数更新
```

每次更新做的事：

```text
前向预测 -> 算 loss -> 反向传播算梯度 -> Adam 更新参数
```

下一批不是重新开始，也不是另训一个模型，而是在上一批更新后的参数上继续。200 个 epoch 结束后，得到的是同一组参数经过 31,400 次更新后的结果。

`fit` 返回的 `history.history["loss"]` 是每个 epoch 的平均 loss。

## 实际跑出来

数字每次会有小差别，大致是：

```text
final training loss: 7.19e-05
Total params: 1,153 (4.50 KB)

x=0.000  pred=1.004   expected=1.000
x=1.571  pred=0.002   expected=0.000
x=3.142  pred=-1.001  expected=-1.000
x=4.712  pred=-0.003  expected=-0.000
x=6.283  pred=1.024   expected=1.000
```

MSE 是 `7.19e-05`，开根号得到 RMSE：

```text
sqrt(7.19e-05) ≈ 0.0085
```

可以粗略理解成：平均误差在 0.0085 左右。目标范围是 `-1~1`，这个误差很小。

## 为什么这一节没有验证集、测试集和回调

这一节的目标是把 `fit`、`predict`、`save` 跑通，不是评估模型好坏。

- 10,000 个点全部用于训练；
- 预测的 5 个点落在训练集覆盖的区间里，不是单独留出的测试样本；
- 没有验证集，就没有 `val_loss` 给 EarlyStopping 监控；
- 回调会引入新概念，先把最基本的训练闭环跑通更重要。

所以 `final training loss` 只说明模型拟合训练集的程度，不能说明它在没见过的数据上怎么样。

下一节 04 会故意把训练集缩到 6 个点，加入验证集、测试集、EarlyStopping 和 ModelCheckpoint，让过拟合真正出现。

## 几个容易糊涂的点

### 模型不是“记住”了 cos 公式

它没有调用 `math.cos`，只是用 1153 个参数和 ReLU 拼近似曲线。

所以它只在训练过的区间 `[0, 2π]` 内比较准。喂 `x=3π` 或 `x=-1`，它可能给出很离谱的值。这叫外推。

### 训练 loss 低，不等于模型好

这次没有分训练集和验证集，loss 是在全部 10,000 个点上算的。模型可能只是把这些点拟合得很好。

真实任务要留验证集和测试集。下一节就做。

### 这是回归，不是分类

- 回归：输出连续值，比如 `cos(x)`；
- 分类：输出类别，比如“有人/没人”。

回归常用 MSE，分类常用交叉熵。最后一层的设计也不一样。

### 为什么不用 accuracy

`accuracy` 是“预测对的比例”，适合分类。这里输出是连续值，预测 `0.998` 和 `1.000` 算不算“对”没有明确边界，所以用 MSE / MAE。

### 每次运行结果会有点不同

因为：

- 权重初始化是随机的；
- `fit` 默认每个 epoch 打乱数据；
- 浮点计算顺序可能有微小差异。

想固定结果，在 import 后加：

```python
tf.keras.utils.set_random_seed(42)
```

同一台机器上会非常接近；不同机器、不同 TensorFlow 版本仍可能有很小差异。

### `model.summary()` 返回 None

它是直接打印到终端，本身返回 `None`。所以不要写：

```python
print(model.summary())
```

那会先打印表格，再打印一个 `None`。

### 模型文件为什么比 4.50 KB 大

`4.50 KB` 只是权重。`.keras` 文件还要存模型结构、优化器状态和元数据，所以是几十 KB。

## 顺手改两下

1. `epochs=50`：训练更快，loss 会变大；
2. `batch_size=256`：每个 epoch 更新次数变少，训练更快，但更新节奏变了；
3. 隐藏层改成 8：参数变少，可能拟合不住；
4. 目标换成 `sin(x)`：结构不用改，看能不能学会；
5. 学习率改成 `1e-2`：观察 loss 是否更抖；
6. 喂 `x=3π`：看外推有多离谱。
